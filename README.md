# 小满 flower 花束图册

这是一个适合“风格仍在调整期”的公开静态花束图册。它不处理下单和库存，重点是让店主先在电脑上整理、筛选、隐藏和删除花束款式，再把更新发布给顾客。

## 顾客访问地址

https://qi-zhang777.github.io/xiaoman-flower-catalog/

## 在电脑上编辑

直接双击：

- `编辑图册.cmd`

它会自动打开 `http://127.0.0.1:4173/`。此时网页右上角会显示“管理图册”；完成后关闭命令窗口即可。

编辑完成后，在 Codex 中说“帮我发布图册更新”，即可把电脑上的最新版同步到顾客网址。

## 已实现

- 顾客模式：查看图册、按价格筛选、搜索、收藏、查看详情
- 仅限店主电脑的管理模式：上传照片、编辑名字/价格/标签/说明、隐藏、删除
- 自动压缩上传图片，数据写入 `catalog.json` 与 `assets/bouquets/`
- 导出和导入 JSON 备份（包含照片）
- 电脑与手机自适应布局
- 公开网站不会显示管理入口，也不能修改图册

## 当前原型的边界

编辑完成后，需要把更新重新发布到 GitHub Pages，顾客才能看到最新版。公开网站本身不需要数据库，因此维护简单、前期可以免费使用。

正式运营后还可以增加：微信/电话咨询入口、独立域名、访问统计与隐私说明。
